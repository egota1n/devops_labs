### Лабораторная работа №4

##### SonarQube

Для контроля качества кода в проекте используется SonarQube. Он позволяет выявлять баги, уязвимости и технический долг, а также отслеживать покрытие кода тестами. Настройка включает указание исходных файлов, тестов и отчетов покрытия (lcov).

После запуска sonar-scanner создается детальный отчет, где видно количество ошибок, предупреждений, дублированного кода, а также процент покрытия тестами. Это помогает поддерживать код чистым, безопасным и легко сопровождаемым.

##### Telegram-бот

Проект включает Telegram-бота на базе библиотеки Telegraf, который взаимодействует с пользователем через чат. Бот поддерживает команды для получения списка задач (/tasks), переключения статуса задачи через кнопки Toggle и редактирования задач через кнопки Edit.
